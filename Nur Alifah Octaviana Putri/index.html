Teori Bootstrap

Bootstrap merupakan framework open-source yang menggabungkan HTML, CSS, dan JavaScript untuk mempercepat pembuatan tampilan web. Dengan Bootstrap, kita tidak perlu merancang dari nol karena sudah tersedia berbagai komponen siap pakai seperti form, tombol, tabel, dan navigasi. Framework ini juga dirancang dengan konsep responsive design, sehingga layout website akan otomatis menyesuaikan ukuran layar, baik di smartphone, tablet, maupun komputer.
